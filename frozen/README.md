# Frozen publication implementation

`SNI_DPC_v9_5_publication.py` is retained unchanged because its executable
body is the implementation used for the submitted benchmark. Do not run a
formatter or rename internal functions in this file. Its SHA-256 is recorded in
`../checksums.sha256` and its relation to the clean API is described in
`../docs/implementation-equivalence.md`.

For normal use, import `SNIDPC` from `src/sni_dpc` instead of importing this
historical compatibility module directly.
